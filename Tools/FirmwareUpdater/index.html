可用
  • Chrome 89+ · Edge 89+ · Opera 75+（桌面版）
不可用
  • Firefox · Safari · 全部手机与平板浏览器

另外，Web Serial 要求安全上下文：页面须经 HTTPS、localhost 或 file:// 打开，普通 http:// 不行。
